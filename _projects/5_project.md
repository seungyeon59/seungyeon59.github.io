[Demo Video](https://youtu.be/2Iy9umJSEdc) · [Live Demo](https://joywalk-small-happiness.dyheo619.chatgpt.site/) · [Slides](https://github.com/seungyeon59/Small-Happiness/blob/main/docs/HackCMU-Slides.pdf) · [Code](https://github.com/seungyeon59/Small-Happiness)

Navigation apps optimize for speed and miss the small, unexpected joys along the way. JoyWalk is a walking-route app built around the Korean idea of *so-hwak-haeng* (小確幸), finding small but certain happiness in everyday moments. Instead of the shortest path, it guides users past "Joy Spots" that other walkers have shared.

- **Joy route recommendation:** Personalizes nearby Joy Spots with hybrid collaborative filtering, then orders the stops as a Hamiltonian path problem using the Google Maps APIs.
- **Share joy moments:** Users capture or upload a moment from where they are, and the app suggests matching emojis from keywords.
- **Real-time discovery:** xAI's Grok with X Search scans recent Pittsburgh posts and turns verifiable, location-tagged ones into map pins. API keys stay server-side.
- **Gen-Z map interface:** Smooth animations, glassmorphism, and a dark "dopamine palette" with neon accents.

**Tech:** Next.js, React, TailwindCSS, Google Maps Platform, xAI Grok, Firebase, MongoDB
